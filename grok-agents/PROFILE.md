# Working profile

Built from the StressTestor GitHub account (68 repositories) and existing working context. This is the safe-to-share version. It names public projects only and excludes private-repo contents, personal details, and anything operational.

## Primary goals

Ship and maintain a security posture across two fronts: defending AI agents at runtime, and stress-testing model behavior. Turn that work into public credibility (newsletter, X, open source) and income (bug bounty, and a set of small shipped products). Build fast and solo, with heavy agent tooling as the force multiplier.

## What the repos show

The account clusters into five bodies of work.

1. Agent security, the largest and most active cluster. Sentinel (runtime defense for CLI AI agents), Ghost (chaos and visibility), Seance (read-only observer), Triad (one-command stand-up with an honest health check), and Wraith (invisible-instruction smuggling and detection). This is a coherent product line, not scattered experiments, and it is where most recent commits land.

2. LLM evaluation. PromptPressure (multi-model prompt runner with auto-scoring and drift tracking), TokenPressureSandbox, CodeEfficiencyEvalTool. The eval discipline (score model behavior, publish numbers) runs through all of them.

3. Bug bounty operations. scopecreep (scope-aware recon), bounty-ops, crosscheck (deterministic security pre-flight before a push or a submission). A real, tooled income stream, not a hobby.

4. Solo-builder and agent tooling. batstack (Claude Code skills), delegate (route work to non-Claude providers to conserve limits), pr-prism (PR triage, the most-starred repo), Agora (multi-agent debate visualizer), pixel-agents-terminal, plus a run of openclaw plugins. Ships small, ships often.

5. Product and creative. LinkDrift / byli (AI-curated link aggregator on an X-data pipeline), calibratediq, Luna and Cortex assistants, several Voyage world-building repos, and generative-art projects (starforge, galaxy-graph). Tolaria is the second-brain vault behind galaxy-graph.

## Recurring workflows

- Run PromptPressure sweeps on new model releases, publish the numbers.
- Extend Sentinel's threat coverage as new agent attacks appear.
- Bug bounty recon and submission, gated by crosscheck pre-flight.
- Write Ghost In The Model Weekly under a strict confidence and voice discipline.
- Post as @ThatbV in a codified voice, coordinate agent work through STs-Mission-Control.

## Important decisions

- When a model change is real enough to spend a sweep on.
- What threat class Sentinel defends against next.
- Whether a claim is solid enough to publish.
- Which thread is worth a reply right now.
- Which bounty program is worth the hours.
- What the crowd actually believes before an earnings print.

## Bottlenecks

Every one of these is the same shape: separating signal from fast live noise, where the primary source is usually a post and the correction is usually a reply. That is precisely the gap live X data closes and a general assistant cannot.

## Strongest leverage

Joe already runs a solid / directional / vibes confidence discipline and a strict voice filter, and already pipes X data programmatically (LinkDrift). Agents that plug into that existing vocabulary and pipeline add capability without adding a second workflow to maintain.

## Topics, people, communities

The communities that matter are the security researchers publishing agent exploits, the eval and red-team crowd, and the solo-builder tooling niche, all of which are most legible on X.
